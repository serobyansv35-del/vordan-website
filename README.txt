VORDAN WEBSITE
================

This folder contains the finished website.

To preview:
1. Open index.html in Chrome/Edge.
2. Everything is already inside the assets folder.

To publish:
- Upload the contents of this folder to GitHub Pages, Netlify, Vercel, or another static hosting service.
- Once you have the public HTTPS URL, a QR code can point directly to that URL.

Important:
A QR code needs a public website URL to be a working scan-to-website QR.
